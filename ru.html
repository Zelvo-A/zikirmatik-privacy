Политика конфиденциальности

Последнее обновление: 17 мая 2026 г. · Дата вступления в силу: 17 мая 2026 г.

Резюме: ZikirMatik Pro не продаёт ваши персональные данные, не собирает email/телефон/настоящее имя и не требует создания аккаунта. При одиночном использовании все данные остаются на вашем устройстве. При использовании функции Группового зикра только данные группы (ник, название группы, счётчики) обрабатываются безопасно на Firebase Firestore. Реклама и телеметрия сбоев анонимны.

1. Контролёр данных

Это приложение разработано и опубликовано Gökay Tutal (zelvoai@gmail.com). Соответствие GDPR / Программе для разработчиков Google Play.

2. Какие данные мы собираем и где они хранятся

2.1 Данные, хранящиеся только на вашем устройстве

  • Ваш список зикров, пользовательские зикры и цели
  • История подсчётов и записи сеансов
  • Настройки: тема, язык, шрифт, звук/вибрация, время уведомлений
  • Состояние принятия онбординга и политики
  • Локальное состояние проверки покупки Premium

2.2 Анонимная аналитика (Firebase)

  • Firebase Analytics: Просмотры экранов, события использования. Без персональных данных.
  • Firebase Crashlytics: Трассировки сбоев, модель устройства, версия Android, анонимный Installation ID.
  • Firebase App Check: Проверяет, что серверные вызовы идут с легитимного устройства/приложения.

2.3 Анонимная глобальная статистика

В коллекцию _globalStats в Firestore отправляются анонимные обновления агрегированных счётчиков. Без идентификатора пользователя, IP или идентификатора устройства.

2.4 Групповой зикр / Хатм (облачные данные)

Эта функция опциональна:

  • Firebase Authentication (анонимно): Случайный UID без email/телефона/настоящего имени.
  • Firestore (us-west1): Название группы, намерение, код приглашения, ваш ник, прогресс задач, список участников, журнал аудита.
  • Cloud Functions: Критические операции на сервере.
  • App Check: Предотвращает поддельных клиентов.

2.5 Реклама (Google AdMob)

  • Без Premium-подписки показываются баннеры и реклама за вознаграждение.
  • AdMob может обрабатывать AD_ID и информацию сессии.
  • Для пользователей ЕЭП/Великобритании/Швейцарии показывается диалог согласия UMP.
  • Персонализированная реклама не показывается без вашего согласия.

2.6 Покупки (Google Play Billing)

Подписка Premium обрабатывается через Google Play. ZikirMatik не видит и не хранит ваш номер карты или платёжную информацию.

3. Местоположение (только Кибла)

Местоположение используется только в Кибла-компасе на устройстве. Никогда не отправляется на сервер и не сохраняется.

4. Камера (только сканирование QR)

Камера открывается только для сканирования QR. Изображение обрабатывается в реальном времени, не сохраняется и не отправляется.

6. Сторонние сервисы

  • Firebase (Analytics, Crashlytics, Auth, Firestore, Cloud Functions, App Check)
  • Google AdMob
  • Google Play Billing
  • Google User Messaging Platform (UMP)

7. Хранение и право на удаление

  • Данные устройства: удаляются при удалении приложения.
  • История подсчётов: можно удалить из приложения.
  • Данные группы: удаляются из Firestore при выходе/удалении группы.
  • Анонимный UID: запрос на zelvoai@gmail.com, удаление в течение 30 дней.
  • Analytics: Firebase Analytics автоудаление через 14 месяцев. Crashlytics: 90 дней.

8. Дети

Приложение не предназначено для детей до 13 лет. Без создания аккаунта и сбора персональных данных.

9. Безопасность данных

  • Связь с Firebase шифруется TLS 1.2+.
  • Правила Firestore: каждый участник читает только свои группы.
  • Cloud Functions проверяют критические операции на стороне сервера.
  • App Check предотвращает поддельных клиентов.

10. Изменения политики

Если политика обновлена, дата "Последнее обновление" будет изменена.
