ZikirMatik Pro Veri Silme

Son guncelleme: 17 Mayis 2026

ZikirMatik Pro e-posta, telefon veya gercek ad ile hesap olusturmaz. Grup/Hatim ozelligi kullanildiginda Firebase tarafinda yalnizca anonim kullanici ID'si ve grup verileri islenir.

Uygulama icinden veri silme

Kullanicilar bulut verilerini uygulama icinden silebilir:

  • Uygulamayi acin.
  • Ayarlar ekranina gidin.
  • Bulut verilerini sil secenegine dokunun.
  • Uyari metnini okuyup onaylayin.

Bu islem Firestore ve Firebase Authentication tarafinda kullaniciya bagli bulut verilerini siler.

Silinen veriler

  • Anonim Firebase Authentication kullanici hesabi.
  • users/{uid} premium bulut yetki kaydi.
  • userGroups/{uid} grup uyelik referanslari.
  • Hatim/grup uyelik kayitlari.
  • Kullaniciya ait gorev ilerlemeleri.
  • Kullaniciya ait fazla okuma kayitlari.
  • Kullaniciya ait supheli islem, admin uyarisi ve denetim kayitlari.
  • _userTrust/{uid} guven/koruma kaydi.
Silme islemi geri alinamaz. Kullanici bir grubun sahibiyse, ilgili grup kapatilabilir ve diger uyelerin grup erisimi etkilenebilir. Cihazdaki yerel sayac gecmisi bu bulut silme islemiyle silinmez; yerel veriler icin uygulama verileri temizlenebilir veya uygulama kaldirilabilir.

Uygulamaya erisemiyorsaniz, veri silme talebinizi asagidaki e-posta adresine iletebilirsiniz. Kayitlari bulabilmemiz icin varsa davet kodu, grup adi veya takma ad bilgisini ekleyin.

Data Deletion for ZikirMatik Pro

Last updated: May 17, 2026

ZikirMatik Pro does not create accounts with email, phone number, or real name. When the Group/Hatim feature is used, Firebase processes only an anonymous user ID and group-related data.

Delete data inside the app

Users can delete their cloud data from inside the app:

  • Open the app.
  • Go to Settings.
  • Tap Delete cloud data.
  • Read the warning and confirm.

This deletes the user's cloud data from Firestore and Firebase Authentication.

Data deleted

  • Anonymous Firebase Authentication user account.
  • users/{uid} premium cloud entitlement record.
  • userGroups/{uid} group membership references.
  • Hatim/group membership records.
  • Task progress created by the user.
  • Extra reading records created by the user.
  • Suspicious activity, admin alert, and audit records related to the user.
  • _userTrust/{uid} trust/protection record.
Data deletion cannot be undone. If the user owns a group, that group may be closed and other members' access may be affected. Local counter history on the device is not deleted by this cloud deletion flow; local data can be removed by clearing app data or uninstalling the app.

If you cannot access the app, send a data deletion request to the email below. Include an invite code, group name, or nickname if available so records can be located.
