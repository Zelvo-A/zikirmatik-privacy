Kebijakan Privasi

Pembaruan terakhir: 28 Oktober 2026 · Berlaku: 28 Oktober 2026

Ringkasan: ZikirMatik Pro tidak menjual data pribadi Anda, tidak mengumpulkan email/telepon/nama asli, dan tidak memerlukan pembuatan akun. Dalam penggunaan mandiri, semua data Anda tersimpan di perangkat. Saat menggunakan fitur Dzikir Grup, hanya data grup (nama panggilan, nama grup, penghitung) yang diproses dengan aman di Firebase Firestore. Telemetri iklan dan crash bersifat anonim.
Papan peringkat grup: Dalam Dzikir Grup, nama panggilan, total zikir (tugas dan hitungan tambahan), serta hari dan jam hitungan Anda (setiap tugas selesai dan setiap hitungan tambahan) hanya terlihat oleh admin grup di papan peringkat; anggota lain tidak melihatnya. Keluar dari grup menghapus Anda dari papan peringkat; menghapus data cloud di aplikasi menghapus semua catatan Anda.

1. Pengendali Data

Aplikasi ini dikembangkan dan diterbitkan oleh Gökay Tutal (zelvoai@gmail.com). Kepatuhan terhadap GDPR / Kebijakan Program Pengembang Google Play berkomitmen.

2. Data yang Kami Kumpulkan dan Tempat Penyimpanan

2.1 Data yang Hanya Tersimpan di Perangkat Anda

  • Daftar dzikir, dzikir kustom, dan target
  • Riwayat penghitungan dan rekam sesi
  • Pengaturan: tema, bahasa, font, suara/getar, waktu notifikasi
  • Status persetujuan onboarding dan kebijakan
  • Status verifikasi pembelian Premium lokal
  • Laporan kesalahan aplikasi: Jenis dan pesan kesalahan, jejak tumpukan, versi aplikasi, versi Android, dan model perangkat dikirim ke server kami (Firebase); tanpa identitas atau data pribadi.
  • Aktivitas harian: Sekali sehari, hash satu arah dari ID instalasi Firebase dan versi aplikasi dikirim (untuk menghitung pengguna harian); ID asli tidak disimpan.
  • Cadangan Google Android: Jika aktif di ponsel Anda, dzikir, riwayat, dan pengaturan Anda dicadangkan terenkripsi ke akun Google Anda; kami tidak dapat mengaksesnya.

2.2 Analitik Anonim (Firebase)

  • Firebase Analytics: Layar yang dilihat, event penggunaan. Tanpa data pribadi.
  • Firebase Crashlytics: Jejak crash, model perangkat, versi Android, Installation ID anonim.
  • Firebase App Check: Memverifikasi panggilan server dari perangkat/aplikasi sah.

2.3 Statistik Global Anonim

Hitungan dzikir disimpan secara default di database lokal perangkat. Pada versi aplikasi saat ini, nama dzikir yang dimasukkan pengguna maupun pembaruan penghitung agregat tidak dikirim ke koleksi statistik jarak jauh manapun.

2.4 Dzikir Grup / Khatam (Data Cloud)

Fitur ini opsional:

  • Firebase Authentication (anonim): UID acak tanpa email/telepon/nama asli.
  • Firestore (us-west1): Nama grup, niat, kode undangan, nama panggilan Anda, progres tugas, daftar anggota, log audit.
  • Cloud Functions: Operasi kritis di server.
  • App Check: Memantau apakah panggilan server berasal dari perangkat dan aplikasi asli; akses otomatis juga dicegah dengan login, aturan, dan batas frekuensi.

2.5 Iklan (Google AdMob)

  • Tanpa langganan Premium, iklan banner dan berhadiah ditampilkan.
  • AdMob dapat memproses AD_ID dan informasi sesi.
  • Untuk pengguna EEA/UK/Swiss, dialog persetujuan UMP ditampilkan.
  • Iklan berhadiah (opsional): Hanya jika Anda memilihnya: 1 video singkat untuk menyembunyikan iklan banner bawah selama 24 jam. Hadiah hanya diberikan jika video ditonton sampai selesai. Seluruh Al-Qur'an tersedia tanpa menonton iklan; kapasitas grup hanya dapat ditambah dengan Premium.
  • Iklan personalisasi tidak ditampilkan tanpa persetujuan Anda.

2.6 Pembelian (Google Play Billing)

Langganan Premium diproses melalui Google Play. ZikirMatik tidak melihat atau menyimpan nomor kartu atau informasi pembayaran.

Jadwal Salat dan Lokasi (Opsional)

  • Lokasi Anda (koordinat perkiraan atau kota yang dipilih) hanya digunakan di ponsel Anda; tidak pernah dikirim ke server mana pun, tidak dimasukkan ke analitik atau laporan error, dan tidak ikut dalam cadangan Google.
  • Di Turki, jadwal diambil dari jadwal resmi per kabupaten milik Kepresidenan Urusan Agama (Diyanet). Jadwal seluruh Turki diunduh setahun sekali sebagai satu berkas dari server kami (Firebase); permintaan ini tidak berisi lokasi atau kabupaten, dan kabupaten terdekat ditentukan di ponsel Anda. Di negara lain, jadwal dihitung di ponsel.
  • Izin lokasi (lokasi perkiraan) bersifat opsional; tanpanya Anda dapat memilih kota dari daftar. Anda dapat mencabutnya kapan saja di pengaturan Android.
  • Saat Anda mencari kota yang tidak ada di daftar, hanya nama kota yang Anda ketik yang dikirim ke layanan pencarian lokasi Android (Google); lokasi perangkat Anda tidak dikirim.
  • Pengingat sahur bersifat opsional dan dijadwalkan di perangkat; Anda dapat mengizinkan “Alarm & pengingat” di pengaturan Android agar tepat waktu.

3. Kamera (Hanya Pemindaian QR)

Kamera hanya terbuka untuk memindai QR. Gambar diproses real-time, tidak disimpan, tidak dikirim.

6. Retensi dan Hak Penghapusan

  • Data perangkat: dihapus saat aplikasi di-uninstall.
  • Riwayat: dapat dihapus dari aplikasi.
  • Data grup: dihapus dari Firestore saat keluar/menghapus grup.
  • Hapus dari dalam aplikasi (disarankan): Pengaturan -> Hapus data cloud — satu ketukan menghapus akun anonim dan semua data grup Anda dari Firestore.
  • Hapus via email: ajukan ke zelvoai@gmail.com, dihapus dalam 30 hari.
  • Analytics: Firebase Analytics auto-hapus setelah 14 bulan. Crashlytics: 90 hari.
  • Laporan kesalahan dan aktivitas harian: Catatan kesalahan disimpan paling lama 180 hari, penanda aktivitas harian 3 hari.

7. Anak-anak

Aplikasi tidak ditujukan untuk anak di bawah 13 tahun. Tanpa pembuatan akun atau pengumpulan data pribadi.

8. Keamanan Data

  • Komunikasi Firebase TLS 1.2+ terenkripsi.
  • Aturan Firestore: setiap anggota hanya membaca grupnya.
  • Cloud Functions memverifikasi operasi kritis di server.
  • App Check (Play Integrity) memantau integritas aplikasi; setiap permintaan juga dilindungi oleh identitas masuk, aturan Firestore, dan batas frekuensi.

9. Perubahan Kebijakan

Jika kebijakan diperbarui, tanggal "Pembaruan terakhir" akan diubah.
